# CompTIA Security+ (SY0-701) Study Knowledge Base

A personal study knowledge base built from bootcamp course slides, used to
track objective coverage, validated notes, and practice performance ahead of
the CompTIA Security+ SY0-701 exam. Notes under `course-unit-notes/` and
`glossary/` are derived/paraphrased from bootcamp material for personal study
— they are not a redistribution of the source slides (which stay local-only
and gitignored).

## Start here

- [`source_coverage/objective_mapping.md`](source_coverage/objective_mapping.md)
  — what's covered vs. outstanding, per official sub-objective.
- [`source_coverage/coverage_tracker.md`](source_coverage/coverage_tracker.md)
  — page-level extraction/validation status across all 659 source slides.
- [`user_progress/study_log.md`](user_progress/study_log.md) — session history.
- [`user_progress/review_queue.md`](user_progress/review_queue.md) —
  prioritized items for the next study session.

## Directory map

| Path | Contents |
|---|---|
| `course-unit-notes/` | Substantive notes, organized by official domain, then by course unit |
| `glossary/` | Concise cross-domain term reference, linking back to detailed notes |
| `user_progress/` | Knowledge profile, assessment history, weakness ledger, review queue, study log (append-only, never overwritten) |
| `source_coverage/` | Objective-to-notes mapping and slide-level coverage tracker |
| `CompTIA_SecurityPlus_Slides/` | Source PDFs (local only, gitignored — not redistributed) |

## Exam target

**CompTIA Security+ SY0-701**, Exam Objectives Version 5.0 (CompTIA, 2023).
90 questions max, 90 minutes, multiple-choice + performance-based.

| # | Domain | Weight |
|---|---|---|
| 1.0 | General Security Concepts | 12% |
| 2.0 | Threats, Vulnerabilities, and Mitigations | 22% |
| 3.0 | Security Architecture | 18% |
| 4.0 | Security Operations | 28% |
| 5.0 | Security Program Management and Oversight | 20% |

See `CLAUDE.md` for the full set of conventions, extraction workflow, and
study-coach behavior governing this repository.
