## Security control categories (Source: Pt1 p.19)

| Category | Slide definition | Slide examples |
|---|---|---|
| Managerial (Administrative) | Implemented by creating and following organizational policy, procedure, or regulation; gives oversight of the information system | Security documentation, risk management, personnel security, data classification, user training and awareness; typically developed and implemented by management |
| Physical | Implemented with physical assets/devices that act against in-person intrusion attempts (limit physical access to building, room, or device) | Alarms, fences, gates, locks, lighting, security cameras, guard shack, guard dogs, and security guards that deter and detect access to premises and hardware |
| Operational | Implemented primarily by people rather than systems | Security guards, training and awareness programs |
| Technical (Logical) | Implemented as a system using software, hardware, or firmware that restricts logical access on an information technology system and requires authentication and auditing | Firewalls, IDS/IPS, routers, encryption, Access Control Lists (ACLs), logon / pop-up banner or a splash screen |

- Callout on the slide: "Technical and Physical controls should be supported with Administrative controls." (Source: Pt1 p.19)
- Slide-wording note: the slide lists the categories in the order Managerial, Physical, Operational, Technical, which differs from the Section Topics order (Technical, Managerial, Operational, Physical). Security guards and training/awareness appear as examples under Operational; security guards also appear under Physical. (Source: Pt1 p.19)

## Security control types (Source: Pt1 p.20)

| Type | Slide definition | Slide examples |
|---|---|---|
| Directive | Instruct on rules of behavior | Laws, regulations, requirements, policies |
| Deterrent | Discourage individuals from attempting to violate security policy or bypass controls | Fences, lighting, cameras, laws, regulations, signs, posters |
| Detective | Send a warning after discovering unwanted activities during or after they have occurred | Alarms, auditing of a database, logs, alerts, Intrusion Detection System (IDS), CCTV; heat/flame/smoke/motion detectors |
| Preventive | Proactively implemented to prevent unwanted activity or from occurring | Firewall, Intrusion Prevention System (IPS), mantraps, security guard, background checks, locks |
| Compensating/Alternative | Implemented to mitigate risk and make up for deficiencies in other controls; meet a requirement when the requirement cannot be directly met | Instead of a security guard use video cameras (CCTV) for surveillance; fire suppression system, backup generator |
| Corrective/Recovery | Post incident mechanisms to fix a problem or to bring a system back to its original baseline state prior to an unwanted activity | Re-image a computer, backups, UPS |

(Source: Pt1 p.20)

- Slide-wording notes: the slide's list order is Directive, Deterrent, Detective, Preventive, Compensating/Alternative, Corrective/Recovery (Section Topics order differs). The slide gives the same item in more than one type: lighting, cameras, and fences under Deterrent; CCTV under Detective and as the compensating substitute for a guard; security guard under Preventive (p.20) and under Physical/Operational (p.19). (Source: Pt1 p.19-20)
