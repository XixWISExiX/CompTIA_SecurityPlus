# Generate a Source-Grounded Security+ Quiz

Read the repository instructions, course notes, objective mapping,
and user_progress/ before generating questions.

Generate a fresh quiz using the extracted bootcamp material.

If I specify an objective, focus on that objective.
Otherwise, prioritize objectives I have studied but have not
demonstrated mastery of.

Requirements:
1. Default to 10 questions unless I specify another count.
2. Use only source-supported facts for questions based on my
   bootcamp. Clearly label any supplemental external knowledge.
3. Cover different concepts rather than repeatedly testing
   the same definition.
4. Include realistic scenarios, troubleshooting, comparisons,
   and plausible distractors.
5. Match the style and difficulty of CompTIA Security+ questions.
6. Include single-answer and multi-answer questions when useful.
7. Ensure each question has a validated answer key and explanation.
8. Record the official objective ID and exact source PDF/part/page
   references for every question.
9. Keep answers, explanations, and citations hidden until I submit
   my responses.
10. Avoid previously used questions unless I explicitly request
    a repeat. New questions may test previously missed concepts.
11. Do not quiz me on unverified slide-specific claims.
12. If the source material is insufficient, flag the gap.

Present only the questions and answer options initially.
Wait for my answers before grading.
Preserve question IDs so my answers can be graded consistently.
